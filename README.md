# 奶茶和干饭日记 🍵🍚

给总是忘记踩雷滋味的自己：下次下单前，先翻一翻。

🍵 **[味道日记](https://grred1.github.io/tea-and-meal-diary/)** · 📅 **[饮食日历](https://grred1.github.io/tea-and-meal-diary/calendar/)**

网站由 GitHub Pages 免费托管，推送到 `main` 后自动更新。日记和照片均为公开内容。

## 一个吃喝本，两种看法

- **味道日记**：保存奶茶和餐食的照片、口味评价与下次点单提醒。
- **饮食日历**：用可爱贴图展示每天的早餐、午餐、晚餐和加餐，保存原始描述、实际份量与已记热量。支持新增、编辑、完整备份导入导出。
- 已确认关联的饮品可以在两边跳转，例如 11 月 4 日的半杯薄荷黑巧；点评本身不另外计入热量。

饮食日历首次打开即加载已公开的 31 笔历史记录（2026-10-26 至 2026-11-05，共 8 天，含热量待确认的喜茶及暂估 88 千卡的麻辣王子辣条）。用户已授权将该快照公开。现有浏览器记录优先，不会被每次刷新覆盖；新地址和旧的 `127.0.0.1:8765` 各有独立存储，如需带入其他本地记录，请从旧页面导出并在新页面导入。

**网页中的后续编辑只保存在当前浏览器，并不会自动同步 GitHub 或其他设备。** 发布更新请导出完整 JSON，替换 `calendar/data/diary-2026-11-05.json`，运行 `python3 scripts/build_calendar.py`，再提交 JSON 与生成的 `calendar/published-data.js`。其他已使用过页面的浏览器可主动导入新备份；详见 [数据说明](calendar/data/README.md)。

热量标签、手动填写值及估算依据会原样保留，未知值不按零处理，部分日期仅有部分餐次。当前高达芝士蛋堡的 350 千卡仍是估算。

## 怎么记

复制 [记录模板](TEMPLATE.md)，放进 `entries/`，照片放进 `photos/`，然后更新上面的目录。保留当时的真实感受，比好看的评分更有用。

## 展示前端：一口备忘录

直接打开 `index.html` 即可浏览，无需安装依赖。支持手机布局、茶饮/干饭分类、关键词搜索和记录详情。

也可以用本地服务器预览：

```bash
python3 -m http.server 8000
```

随后打开 http://localhost:8000 。

新增或修改 `entries/*.md` 后，更新展示数据：

```bash
python3 scripts/build.py
```

将更新后的 `data.js` 与日记、照片一起提交即可。味道日记前端从 Markdown 提取内容，日期字段表示记录日期；这一部分仍由文件维护。饮食日历则可以在网页中编辑。
