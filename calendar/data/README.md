首次打开饮食日历时自动载入公开快照。已有浏览器记录优先，刷新不会覆盖编辑或恢复已删除项。要主动恢复或更新快照，在页面选择“导入”并选择此 JSON；按 ID 合并，冲突时确认后覆盖，可撤销。

浏览器中的后续修改不会自动写入 GitHub。更新步骤：导出完整备份 → 替换此 JSON → 运行 `python3 scripts/build_calendar.py` → 运行 `node calendar/test.js` 和 `node calendar/published.test.js` → 将 JSON 和生成的 `calendar/published-data.js` 一起提交。

同一记录中的手动热量直接保留，不能根据默认份量重新计算覆盖。部分日期记录不完整，页面显示的是“已记热量”。
